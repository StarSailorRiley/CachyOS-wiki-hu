A teljesítményoptimalizált disztribúció leszállítására irányuló célunk megköveteli az alapvető Arch Linux csomagok újrakompilálását x86-64-v3, x86-64-v4 és Zen4 architektúrákra.

- **x86-64-v3:** 5%-20%-os teljesítménynövekedés az x86-64-hez képest.
- **x86-64-v4:** Jelentős teljesítménynövekedést biztosít az AVX512 támogatásnak köszönhetően, a munkaterheléstől függően.
- **Zen 4/5:** Az x86-64-v4 utasításkészlet mellett a következőket adjuk hozzá:

```text
abm, adx, aes, avx512bf16, avx512bitalg, avx512ifma, avx512vbmi, avx512vbmi2, avx512vnni,
avx512vpopctndq, clflushopt, clwb, clzero, fsgsbase, gfni, mwaitx, pclmul, pku, prfchw,
rpdid, rdrnd, rdseed, sha, sse4a, vaes, vockmulqdq, wbnoinvd, savec, xsaveopt, xsaves
```

## Testreszabott csomagok

A [CachyOS-PKGBUILDs](https://github.com/CachyOS/CachyOS-PKGBUILDS) repository olyan csomagokat tartalmaz, amelyek folyamatosan frissítéseket, javításokat és visszamenőlegesen portolt hibajavításokat kapnak.
A teljesítmény növelése érdekében igény szerint szelektíven implementálunk PGO, LTO és BOLT optimalizálásokat.
Emellett néhány -git csomagot is karbantartunk, pl. a mesa-git-et.

## Repository-ink hozzáadása egy meglévő Arch Linux telepítéshez

:::caution[Figyelem]
A CachyOS Pacman telepítése egy forkolt pacmant telepít, amely a CachyOS által hozzáadott funkciókat tartalmaz, mint például az "INSTALLED_FROM" és egy automatikus architektúra-ellenőrzés. A Pacman 6.1 egy funkció-érvényesítési funkciót adott hozzá, amely az Arch Linux pacman használatakor figyelmeztetésekhez vezethet. Az Arch Linuxszal dolgozunk azon, hogy ismét megfelelő kompatibilitást biztosítsunk. Ha ezt el szeretné kerülni, ne adja hozzá a "cachyos" repositoryt, amely a testreszabott pacmant tartalmazza. Minden más repository, mint például a cachyos-v3, cachyos-v4, cachyos-extra/core-v3/4, hozzáadható.
:::

:::tip[Tipp]
Mielőtt fontolóra venné a repository-k ​hozzáadását, kérjük, tekintse meg a **[CPU kompatibilitási listát](/hu/installation/installation_prepare#x86_64-mikroarchitektúra-szintű-támogatás)**
:::

<Tabs>

<TabItem label='Automatizált'>

Biztosítunk egy szkriptet, amely automatizálja a repository-aink ​​telepítését a meglévő Arch-alapú installjára.

```sh
curl https://mirror.cachyos.org/cachyos-repo.tar.xz -o cachyos-repo.tar.xz
tar xvf cachyos-repo.tar.xz && cd cachyos-repo
sudo ./cachyos-repo.sh
```

:::tip[Hogyan működik a szkript]
Ez a szkript felismeri a CPU-d által támogatott utasításkészleteket, és telepíti a tárolóink ​​azon verzióit, amelyek a leginkább optimalizáltak rá. Emellett biztonsági másolatot készít a régi `pacman.conf` fájlról, hogy a szkript eltávolíthassa a repo-kat.
:::

</TabItem>

<TabItem label='Manuális'>

<Steps>

1. Telepítse a CachyOS keyring-et:

   ```sh
   # Importálja a repository key-t
   sudo pacman-key --recv-keys F3B607488DB35A47 --keyserver keyserver.ubuntu.com
   # Írja alá a repository key-t
   sudo pacman-key --lsign-key F3B607488DB35A47
   ```
2. Telepítse a szükséges csomagokat:

   ```sh
   sudo pacman -U 'https://mirror.cachyos.org/repo/x86_64/cachyos/cachyos-keyring-20240331-1-any.pkg.tar.zst' \
   'https://mirror.cachyos.org/repo/x86_64/cachyos/cachyos-mirrorlist-22-1-any.pkg.tar.zst' \
   'https://mirror.cachyos.org/repo/x86_64/cachyos/cachyos-v3-mirrorlist-22-1-any.pkg.tar.zst' \
   'https://mirror.cachyos.org/repo/x86_64/cachyos/cachyos-v4-mirrorlist-22-1-any.pkg.tar.zst' \
   'https://mirror.cachyos.org/repo/x86_64/cachyos/pacman-7.0.0.r6.gc685ae6-3-x86_64.pkg.tar.zst'
   ```
3. Adja hozzá a CachyOS repository-kat a pacman konfigurációs fájljához:
   :::note[Megjegyzés]
   Ezeket a repository-kat az Arch Linux adattárak fölé kell helyezni.
   :::

   ```shell
   # /etc/pacman.conf
   # Ha a CPU csak az x86-64-et támogatja, akkor adja hozzá a [cachyos] repository-kat
   # cachyos repos
   [cachyos]
   Include = /etc/pacman.d/cachyos-mirrorlist

   # Ha a CPU támogatja az x86-64-v3-at, akkor adja hozzá a [cachyos-v3],[cachyos-core-v3],[cachyos-extra-v3] és [cachyos] repository-kat
   # cachyos repos

   [cachyos-v3]
   Include = /etc/pacman.d/cachyos-v3-mirrorlist
   [cachyos-core-v3]
   Include = /etc/pacman.d/cachyos-v3-mirrorlist
   [cachyos-extra-v3]
   Include = /etc/pacman.d/cachyos-v3-mirrorlist
   [cachyos]
   Include = /etc/pacman.d/cachyos-mirrorlist

   # Ha a CPU támogatja az x86-64-v4-et, akkor adja hozzá a [cachyos-v4], [cachyos-core-v4], [cachyos-extra-v4] és [cachyos] repository-kat
   # cachyos repos

   [cachyos-v4]
   Include = /etc/pacman.d/cachyos-v4-mirrorlist
   [cachyos-core-v4]
   Include = /etc/pacman.d/cachyos-v4-mirrorlist
   [cachyos-extra-v4]
   Include = /etc/pacman.d/cachyos-v4-mirrorlist
   [cachyos]
   Include = /etc/pacman.d/cachyos-mirrorlist

   # Ha a CPU Zen 4 vagy Zen 5 alapú, adja hozzá a [cachyos-znver], [cachyos-core-znver4], [cachyos-extra-znver4] és [cachyos] respository-kat
   # cachyos repos

   [cachyos-znver4]
   Include = /etc/pacman.d/cachyos-v4-mirrorlist
   [cachyos-core-znver4]
   Include = /etc/pacman.d/cachyos-v4-mirrorlist
   [cachyos-extra-znver4]
   Include = /etc/pacman.d/cachyos-v4-mirrorlist
   [cachyos]
   Include = /etc/pacman.d/cachyos-mirrorlist
   ```
      :::tip[Tipp]
   A `v4` repository-król a `znver4` repository-kra való átálláshoz:

   Adja hozzá az előző lépésből származó megfelelő bejegyzéseket, és futtassa a következő parancsokat:
    ```sh
    sudo pacman -Scc # Y mindkétszer
    sudo pacman -Sy
    pacman -Qqn | sudo pacman -S - # Az összes v4 csomag lecserélése a znver4 csomagokra
    # Indítsa újra a rendszert
    ```
   :::

4. Végül frissítse a rendszert CachyOS-csomagokkal:
   ```sh
   sudo pacman -Syu
   ```

</Steps>

</TabItem>

### CachyOS repository-k eltávolítása

<Tabs>
<TabItem label='Automatizált'>

**A CachyOS repository-k rendszerből való eltávolításához futtassa a következő parancsokat:**
```sh
curl https://mirror.cachyos.org/cachyos-repo.tar.xz -o cachyos-repo.tar.xz
tar xvf cachyos-repo.tar.xz
cd cachyos-repo
sudo ./cachyos-repo.sh --remove
```

</TabItem>

<TabItem label='Manuális'>

<Steps>

1. Telepítse újra az eredeti pacmant az Arch Linuxtól:
   ```sh
   sudo pacman -S core/pacman
   ```
2. Futtassa a következő parancsot:
   ```sh
   # Ez elkerüli az %INSTALLED_DB% figyelmeztetéseket
   sudo find /var/lib/pacman/local/ -type f -name "desc" -exec sed -i '/^%INSTALLED_DB%$/,+2d' {} \;
   ```
3. Készítsen biztonsági másolatot a pacman konfigurációs fájljáról:
   ```sh
   sudo mv /etc/pacman.conf.bak /etc/pacman.conf
   ```
4. Váltson vissza az alapértelmezett Arch Linux csomagokra a következő parancsokkal:
   ```sh
   pacman -Qqn | sudo pacman -S -
   sudo pacman -Syu
   ```
</Steps>

</TabItem>

## Tesztek és benchmarkok

Michael a Phoronixtól már néhányszor tesztelte a CachyOS-t, ami többnyire a benchmark grafikonokon és az összes teszteredmény geometriai átlagán mutatkozott vezetőnek.
A 2022-ben elvégzett első benchmark óta a CachyOS sokat fejlődött és érettebb lett a használhatóság és a teljesítmény tekintetében.

Ha többet szeretne megtudni a repository-jaink ​​teljesítménynövekedéséről, kérjük, tekintse meg az alábbi linkeket.

* **2021/03/14.:** Egy, az x86-64-v3 hatásáról szóló RFC-vita, amelyet **Mateusz Jończyk** indított az Arch Linuxtól, bemutatott néhány kezdeti eredményt.
  * [RFC: Use x86_64-v2 architecture](https://lists.archlinux.org/pipermail/arch-general/2021-March/048739.html)

* **2022/12/09.:** Michael első benchmarkja.
  * [The Performance Of Arch Linux Powered CachyOS](https://www.phoronix.com/review/cachyos-linux-perf)

* **2024/02/29.:** A Phoronix egy újabb benchmarkot végzett, amely bemutatta az x86-64-v4, x86-64-v3 és x86-64 (általános) csomagok közötti különbséget. A PHP vagy a GCC példáit tekintve, ahol testreszabtuk a PKGBUILD-jeinket, észrevehető teljesítményjavulás tapasztalható.
  * [Arch Linux CachyOS Benchmarks Of x86-64-v3 & x86-64-v4 Repositories](https://www.phoronix.com/review/cachyos-x86-64-v3-v4)

* **2024/08/20.:** Michael új benchmarkot tett közzé az AMD Ryzen 9950x-hez, amelyen a CachyOS és néhány más Linux disztribúció is megtalálható.
  * [Intel Continues To Show AMD The Importance Of Software Optimizations: 16% More Ryzen 9 9950X Performance](https://www.phoronix.com/review/linux-os-amd-ryzen9-9950x)
   :::note[Megjegyzés]
   A Liquid-DSP és a RocksDB a Phoronix Benchmark Suite segítségével lettek kompilálva, figyelmen kívül hagyva az /etc/makepkg.conf fájlban megadott fordítási jelzőket, ami váratlan teljesítményeredményt eredményezett a CachyOS esetében.
   :::
