## ISO (lemezkép) letöltése

A CachyOS ISO a következő forrásokból szerezhető be:

*   [Weboldal](<https://cachyos.org/download>)
*   [SourceForge](<https://sourceforge.net/projects/cachyos-arch/files/>)
*   [CachyOS Letöltési Tükör](<https://mirror.cachyos.org/ISO/>)

## ISO integritásának ellenőrzése SHA256-tal

:::caution[FIGYELEM]
Mindig tegyen egy plusz lépést az ISO integritásának ellenőrzésére, hogy elkerülje a nem kívánt problémákat a telepítés vagy a telepítési adathordozó létrehozása során.
:::

**Jelenlegi ISO verzió:** `250422`

**SHA256 Hash (Ellenőrző összeg):** `c87272fc0e8476ea187005d416fa0ee7630a50c71c097233960a0fee22cb8bfe`

<Tabs>

<TabItem label='Windows'>

<Steps>

1. Töltsd le a [fájlt](https://mirror.cachyos.org/ISO/desktop/250422/cachyos-desktop-linux-250422.iso.sha256), amely tartalmazza a SHA256 hash-t **(Nyisd meg egy szövegszerkesztővel, pl.: Jegyzettömb).**
2. Nyisd meg a parancssort vagy a PowerShellt rendszergazdaként, és [lépjen](<https://www.wikihow.com/Change-Directories-in-Command-Prompt>) abba a mappába, ahol az ISO és az SHA256 fájlok találhatók.
3. Hajtsd végre a következő parancsot:
   ```powershell
   # Példa:
   certUtil -hashfile cachyos-desktop-linux-250422.iso SHA256
   ```
4. Hasonlítsd össze a certUtil hash kimenetét az **1. lépésben** letöltött fájl kimenetével. Ha egyeznek, folytathatod a CachyOS telepítését.
</Steps>

</TabItem>

<TabItem label='Linux'>

<Steps>

1. Download the [file](https://mirror.cachyos.org/ISO/desktop/250422/cachyos-desktop-linux-250422.iso.sha256) containing the SHA256 hash.
2. Open a terminal and navigate to the directory containing the `.sha256` file and execute the following commands:
   ```sh
   # Example:
   cd Downloads/
   cat cachyos-desktop-linux-250422.iso.sha256
   # c87272fc0e8476ea187005d416fa0ee7630a50c71c097233960a0fee22cb8bfe
   ```
3. Compare the output from **Step 2** and execute the following command to check what's the current hash in the ISO file.
   ```sh
   # Example:
   sha256sum cachyos-desktop-linux-250422.iso
   ```
4. If the hashes from **Step 2** and **Step 3** match, you can proceed with the CachyOS installation.

</Steps>

</TabItem>

<Steps>

## Verify ISO Image Authenticity (Linux)

To verify the authenticity of the ISO file to be sure that the actual one has been released by the official CachyOS development team:

<Steps>

1. Import the GPG key for verifying the authenticity:

   ```shell
   gpg --keyserver hkps://keys.openpgp.org --recv-key F3B607488DB35A47
   ```

2. Download the ISO file and its `.sig` signature file and run the following command (by replacing `full_iso_name.iso` with the actual ISO filename):
   ```shell
   gpg --verify full_iso_name.iso.sig full_iso_name.iso
   ```

   If you get a **Good signature** output, the ISO file is genuine:
   ```
   gpg: Signature made Mo 01 Apr 2024 14:13:30 CEST
   gpg:                using RSA key 882DCFE48E2051D48E2562ABF3B607488DB35A47
   gpg: Good signature from "CachyOS <admin@cachyos.org>" [unknown]
   gpg: WARNING: This key is not certified with a trusted signature!
   gpg:          There is no indication that the signature belongs to the owner.
   Primary key fingerprint: 882D CFE4 8E20 51D4 8E25  62AB F3B6 0748 8DB3 5A47
   ```

</Steps>

:::danger
If the output does not return **Good signature** string or the key ID does not match, don't use the ISO image and make sure that the downloaded image comes
from a legitimate CachyOS source. A bad signature could suggest that the downloaded image has been tampered with.
:::
