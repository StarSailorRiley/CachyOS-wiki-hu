## ISO (lemezkép) letöltése

A CachyOS ISO a következő forrásokból szerezhető be:

*   [Weboldal](<https://cachyos.org/download>)
*   [SourceForge](<https://sourceforge.net/projects/cachyos-arch/files/>)
*   [CachyOS Letöltési Tükör](<https://mirror.cachyos.org/ISO/>)

## ISO integritásának ellenőrzése SHA256-tal

:::caution[FIGYELEM]
Mindig tegyen egy plusz lépést az ISO integritásának ellenőrzésére, hogy elkerülje a nem kívánt problémákat a telepítés vagy a telepítési adathordozó létrehozása során.
:::

**Jelenlegi ISO verzió:** `250422`

**SHA256 Hash (Ellenőrző összeg):** `c87272fc0e8476ea187005d416fa0ee7630a50c71c097233960a0fee22cb8bfe`

<Tabs>

<TabItem label='Windows'>

<Steps>

1. Töltse le a SHA256 hash-t tartalmazó [fájlt](https://mirror.cachyos.org/ISO/desktop/250422/cachyos-desktop-linux-250422.iso.sha256) **(Nyissa meg egy szövegszerkesztővel, pl.: Jegyzettömb).**
2. Nyissa meg a parancssort vagy a PowerShellt rendszergazdaként, és [lépjen](<https://www.wikihow.com/Change-Directories-in-Command-Prompt>) abba a könyvtárba, ahol az ISO és a SHA256 fájlok találhatók.
3. Futtassa a következő parancsot:
   ```powershell
   # Példa:
   certUtil -hashfile cachyos-desktop-linux-250422.iso SHA256
   ```
4. Hasonlítsa össze a certUtil hash kimenetét az **1. lépésben** letöltött fájl ellenőrző összegével. Ha egyeznek, folytathatja a CachyOS telepítését.
</Steps>

</TabItem>

<TabItem label='Linux'>

<Steps>

1. Töltse le a SHA256 hash-t tartalmazó [fájlt](https://mirror.cachyos.org/ISO/desktop/250422/cachyos-desktop-linux-250422.iso.sha256)
2. Nyisson meg egy terminált, lépjen be a `.sha256` fájlt tartalmazó könyvtárba, és futtassa a következő parancsokat:
   ```sh
   # Példa:
   cd Downloads/
   cat cachyos-desktop-linux-250422.iso.sha256
   # c87272fc0e8476ea187005d416fa0ee7630a50c71c097233960a0fee22cb8bfe
   ```
3. Hasonlítsa össze a **2. lépés** kimenetét, és futtassa a következő parancsot a jelenlévő ISO fájl hash-értékének ellenőrzéséhez.
   ```sh
   # Példa:
   sha256sum cachyos-desktop-linux-250422.iso
   ```
4. Ha a **2. lépés** és a **3. lépés** ellenőrző összegei megegyeznek, folytathatja a CachyOS telepítését.

</Steps>

</TabItem>

<Steps>

2. Nyisson meg egy terminált, lépjen be a `.sha256` fájlt tartalmazó könyvtárba, és futtassa a következő parancsokat:

## ISO-kép hitelességének ellenőrzése (Linux)

Az ISO-fájl hitelességének ellenőrzéséhez, hogy megbizonyosodjon arról, hogy a hivatalos CachyOS fejlesztőcsapat adta ki a jelenlévő fájlt:

<Steps>

1. Importálja a GPG-kulcsot a hitelesség ellenőrzéséhez:

   ```shell
   gpg --keyserver hkps://keys.openpgp.org --recv-key F3B607488DB35A47
   ```

2. Töltse le az ISO fájlt és a hozzá tartozó `.sig` signature fájlt, és futtassa a következő parancsot (a `full_iso_name.iso` helyére a jelenlévő ISO-fájlnév kerül):
   ```shell
   gpg --verify full_iso_name.iso.sig full_iso_name.iso
   ```

   Ha **Good signature** kimenetet kap, az ISO-fájl hiteles:
   ```
   gpg: Signature made Mo 01 Apr 2024 14:13:30 CEST
   gpg:                using RSA key 882DCFE48E2051D48E2562ABF3B607488DB35A47
   gpg: Good signature from "CachyOS <admin@cachyos.org>" [unknown]
   gpg: WARNING: This key is not certified with a trusted signature!
   gpg:          There is no indication that the signature belongs to the owner.
   Primary key fingerprint: 882D CFE4 8E20 51D4 8E25  62AB F3B6 0748 8DB3 5A47
   ```

</Steps>

:::figyelem
Ha a kimenet nem ad vissza **Good signature** karakterláncot, vagy a kulcsazonosító nem egyezik, ne használja az ISO-képet, és győződjön meg arról, hogy a letöltött kép
hiteles CachyOS forrásból származik. Egy rossz signature arra utalhat, hogy a letöltött képet manipulálták.
:::
