## Rendszerkövetelmények

A telepítési előkészületek megkezdése előtt győződjön meg arról, hogy a használt számítógép megfelel a CachyOS futtatásához szükséges rendszerkövetelményeknek. A telepítő online telepítési folyamatot használ, így stabil és viszonylag gyors internetkapcsolat szükséges.

<Tabs>

<TabItem label="Minimum követelmények">

*   3 GB RAM
*   30 GB szabad hely (HDD/SSD)
*   Stabil internetkapcsolat

:::figyelem
Az instabil internetkapcsolat elhúzódó telepítési időt, vagy legrosszabb esetben sikertelen telepítést okozhat
:::

</TabItem>

<TabItem label="Ajánlott követelmények">

*   8 GB RAM
*   50 GB szabad hely (SSD/NVMe)
*   [x86-64-v3 kompatibilis CPU](/installation/installation_prepare#x86_64-microarchitecture-level-support)
*   50 Mbps vagy jobb internetsebesség
*   NVIDIA GPU (900+ - pl.: GTX 950), AMD +GCN 1.0 (pl.: AMD R7 240) vagy Intel (Integrated HD Graphics sorozat vagy újabb Arc sorozat)

</TabItem>

</Tabs>

## Bootolható CachyOS USB-meghajtó létrehozása

Számos eszköz és módszer létezik a CachyOS indítható USB-meghajtójának létrehozásához.

:::note
Az USB-meghajtónak legalább 8 GB szabad tárhellyel kell rendelkeznie.
:::

### balenaEtcher

<Steps>

1. Töltse le a [balenaEtcher](<https://etcher.balena.io/>)-t. A balenaEtcher támogatja a Linux, MacOS és Windows rendszerképek flashelését.
   Ha egy `.zip` fájlt töltött le, csomagolja ki, és futtassa a bináris fájlt a következő parancsokkal:
      ```sh
      # Csomagolja ki a zip fájlt:
      bsdtar xvf <zip file name>
      # Lépjen az új mappába:
      cd balenaEtcher-linux-x64/
      # Futtassa a balenaEtcher-t:
      ./balena-etcher
      ```
2. Csatlakoztasson egy USB-meghajtót a számítógéphez.
3. Válassza ki a **`Flash from file`** lehetőséget, és válassza ki a CachyOS ISO-képfájlt.
4. Kattintson a **`Select target`** gombra, és válassza ki a korábban csatlakoztatott USB-meghajtót.
5. Nyomja meg a **`Flash`** gombot a flashelési folyamat elindításához.

</Steps>

:::note
A balenaEtcher rendszergazdai jogosultságokat kérhet. Ebben az esetben adja meg jelszavát, és kattintson a **`Hitelesítés`** gombra.
:::

### Parancssoros felület (Linux és MacOS)

<Steps>

1. Csatlakoztasson egy USB-meghajtót.
2. A csatlakoztatott USB-meghajtó észleléséhez használja a következő parancsokat:
   ```sh
   # Linux
   # Az USB-meghajtó azonosítható pl.: /dev/sda, a lemez modellje és mérete alapján.
   sudo fdisk -l

   # MacOS
   # Az USB-meghajtók "/dev/diskY" néven vannak azonosítva, ahol az "Y" lehet 0, 1 stb.
   diskutil list
   ```
3. Másolja az ISO tartalmát a csatlakoztatott USB-meghajtóra a következő parancs futtatásával:
   ```sh
   # Cserélje ki az <usbdrive> részt a meghajtó címkéjére.
   sudo dd bs=4M if=full_iso_name.iso of=/dev/<usbdrive> status=progress oflag=sync
   ```
</Steps>

- A `dd` most átmásolja az ISO fájl tartalmát a csatlakoztatott USB-meghajtóra.

### Rufus (Csak Windows)

<Steps>

1. Csatlakoztasson egy USB-meghajtót.
2. Töltse le a [Rufus](<https://rufus.ie/>)-t és telepítse, vagy futtassa a hordozható verziót.
3. A **`Device`** alatt kattintson a legördülő listára, és válassza ki a csatlakoztatott USB-meghajtót.
4. A **`Boot selection`** , alatt kattintson a **`SELECT`** gombra, és keresse meg a CachyOS ISO-képfájlt.
5. Kattintson a **`START`** gombra.

</Steps>

### Ventoy (Linux és Windows)

<Tabs>

<TabItem label="Linux">

<Steps>

1. Csatlakoztasson egy USB-meghajtót.
2. Töltse le a [Ventoy](<https://www.ventoy.net/en/download.html>)-t
3. Csomagolja ki a Ventoy csomagot a következő paranccsal:
   ```sh
   # Cserélje ki a verziót a megfelelőre, pl.: ventoy-1.0.99-linux.tar.gz
   bsdtar xvf ventoy-version-linux.tar.gz
   # cd paranccsal lépjen az új mappába: (a verzió változhat)
   cd ventoy-1.0.99/
   ```
4. Futtassa a **`VentoyGUI.x86_64`** parancsot dupla kattintással vagy a parancssoron keresztül:
   ```sh
   # Rendszergazdai jogosultságokat fog kérni, adja meg a hitelesítő adatait
   ./VentoyGUI.x86_64
   ```
5. Válassza ki a csatlakoztatott USB-meghajtót a **`Device`** gombra kattintva.
6. Kattintson az **`Install`** gombra.
7. Miután befejezte a Ventoy telepítését a csatlakoztatott USB-meghajtóra, zárja be az ablakot, és helyezze a CachyOS ISO-fájlt a meghajtó új, használható partíciójába.

</Steps>

</TabItem>

<TabItem label="Windows">

<Steps>
1. Csatlakoztasson egy USB-meghajtót.
2. Töltse le a [Ventoy](<https://www.ventoy.net/en/download.html>)-t
3. Futtassa a **`Ventoy2Disk.exe`** fájlt
4. Válassza ki a csatlakoztatott USB-meghajtót a **`Device`** gombra kattintva.
5. Kattintson az **`Install`** gombra.
6. Miután befejezte a Ventoy telepítését a csatlakoztatott USB-meghajtóra, zárja be az ablakot, és helyezze a CachyOS ISO-fájlt a meghajtó új, használható partíciójába.
</Steps>

</TabItem>

</Tabs>
