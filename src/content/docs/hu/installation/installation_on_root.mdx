Ellenkező esetben folyamatos hibák léphetnek fel a telepítési folyamat során.

Ez azért történik, mert a telepítő nem tudja megfelelően unmountolni a partíciókat egy sikertelen telepítés esetén.

:::

## Lemez törlése

A Calamares „Lemez törlése” opciója törli a kiválasztott lemezt, és telepíti a CachyOS-t a célhelyre.

<Steps>

1. Indítsa el az ISO-t, és kattintson a **Telepítő indítása** gombra.

2. Válassza ki a kívánt **Boot manager**-t. További információkért tekintse meg a [Boot managerek](/installation/boot_managers) részt.

3. Állítsa be a kívánt **Nyelv** és **Régió/Időzóna** beállításokat.

4. Konfigurálja a **Billentyűzetkiosztás** beállításokat.

5. Válassza a **Lemez törlése** lehetőséget, és válasszon egy [Fájlrendszer](/installation/filesystem) lehetőséget.

6. Válassza ki a kívánt **Desktop környezetet**, lásd: [Desktop környezetek](/installation/desktop_environments).

7. Szabja testre, hogy mely csomagokat kell és nem kell telepíteni a telepítési folyamat során.

8. Állítsa be a bejelentkezési adatokat.

9. Gondosan olvassa el a telepítési összefoglalót az Áttekintés oldalon. Ha minden helyesnek tűnik, folytassa a telepítést a ***Telepítés most*** gombra kattintva. Ellenkező esetben térjen vissza, és végezze el a szükséges módosításokat.

</Steps>

## Kettős rendszerindítás (Dual Booting)

*Manuális particionálás után további beállításokra lehet szükség a kettős rendszerindítású rendszer konfigurálásához, különösen a `systemd-boot` és a `GRUB` használatával.*

<Tabs>
    <TabItem label='systemd-boot'>
        *A Windows EFI binárisokat át kell másolnunk a Linux EFI partícióra, hogy a rendszerindító kezelő felismerhesse őket.*

        <Steps>
        1. Keresse meg a `Windows EFI partíciót` az `lsblk` paranccsal

            ```sh title='Példa'
            ❯ lsblk -o NAME,FSTYPE,SIZE,MOUNTPOINT
            NAME        FSTYPE   SIZE MOUNTPOINT
            zram0               15.3G [SWAP]
            nvme0n1            476.9G
            ├─nvme0n1p1 vfat     100M
            ├─nvme0n1p2           16M
            ├─nvme0n1p3 ntfs   234.4G
            ├─nvme0n1p4 ntfs     830M
            ├─nvme0n1p5 vfat       2G /boot
            └─nvme0n1p6 btrfs  239.6G /var/tmp
            ```

            *Az EFI partíciók szinte mindig `FAT32/vfat` formátumúak, és mivel az nvme0n1p1-nek nincs Linux csatolási pontja, feltételezzük, hogy ez a partíció a `Windows EFI partíció`.*

        2. Ideiglenesen mountolja a `Windows EFI partíciót`.

            ```sh
            ❯ sudo mount /dev/nvme0n1p1 /mnt/WinBoot # Cserélje ki az `nvme0n1p1`-et a Windows EFI partíciójának nevére
            ```

        3. Másolja az EFI binárisokat a `Windows EFI partícióról` a `Linux EFI partícióra`.

            ```sh
            ❯ sudo cp -r /mnt/WinBoot/EFI/* /boot/EFI
            ```

        4. Unmountolja a korábban mountolt partíciót, és a Windowsnak meg kell jelennie a boot menüben a következő indításkor.

            ```sh
            ❯ sudo umount /mnt/WinBoot
            ```

        </Steps>
    </TabItem>

    <TabItem label='GRUB'>
        *A GRUB az os-prober-t használja a Windows EFI partíció automatikus felismeréséhez és a rendszerindító menübe való felvételéhez.*

        <Steps>
        1. Telepítse és futtassa az `os-prober`-t

            ```sh
            ❯ sudo pacman -S os-prober
            ❯ sudo os-prober
            ```

        2. Engedélyezze az `os-prober` parancsot a GRUB konfigurációs fájljában

            ```sh title='Press CTRL+S to save and CTRL+Q to exit from Micro'
            ❯ sudo micro /etc/default/grub
            # /etc/default/grub
            # Probing for other operating systems is disabled for security reasons. Read
            # documentation on GRUB_DISABLE_OS_PROBER, if still want to enable this
            # functionality install os-prober and uncomment to detect and include other
            # operating systems.
            GRUB_DISABLE_OS_PROBER=false

            ❯ sudo grub-mkconfig -o /boot/grub/grub.cfg
            ```

            **A Windowsnak most már hozzá kell tartoznia a boot menühöz.**

        </Steps>
    </TabItem>
</Tabs>
